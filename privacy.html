Verantwortliche Stelle

Dies ist eine private Hobby-Seite. Der Betreiber ist Julius Bruckner. Für Anfragen nutze bitte die im Impressum angegebene Kontaktmöglichkeit.

Datenverarbeitung auf dieser Seite

Diese Website setzt keine Cookies, kein Tracking und keine Analyse-Tools ein.

Adresssuche

Wenn du eine Adresse suchst, wird dein Suchbegriff zur Verarbeitung an den öffentlichen Dienst Nominatim der OpenStreetMap Foundation gesendet. Es werden keine Cookies gespeichert. Die Datenverarbeitung erfolgt zur Bereitstellung der angeforderten Funktion.

Standortfunktion

Die Standortabfrage erfolgt nur nach ausdrücklichem Klick auf „Mein Standort“ über die Geolocation-API deines Browsers. Der Standort wird im Browser verwendet und nicht an Dritte gesendet.

Kartendaten

Die Karte nutzt Kacheln von OpenStreetMap. Beim Laden werden deine IP-Adresse und technische Anfragedaten an die Server von OpenStreetMap übertragen.

Externe Inhalte

Die Leaflet-Bibliothek wird über das Content Delivery Network cdnjs.cloudflare.com geladen. Dabei wird deine IP-Adresse technisch übertragen.

Deine Rechte

Du hast jederzeit das Recht, Auskunft, Berichtigung oder Löschung deiner gespeicherten Daten zu verlangen. Diese Seite speichert jedoch keine Nutzerdaten.
